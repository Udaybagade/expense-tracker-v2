# Expense Tracker System

A full-stack Expense Tracker application built using Spring Boot, Spring Security, JWT, Hibernate, MySQL, HTML, CSS and JavaScript.

## Features

- User Registration
- JWT Authentication
- Category Management
- Expense Management
- Expense Summary
- Validation and Exception Handling

## Technologies

- Java 21
- Spring Boot
- Spring Security
- JWT
- Hibernate
- MySQL
- HTML/CSS/JavaScript

## Run Project

1. Clone repository
2. Create MySQL database
3. Update application.properties
4. Run application

```bash
mvn spring-boot:run
